# Modern Canvas Studio

reimagine the photoshop ui in the latest trendy rounded corner (radius) style and other ui styling trends, to make it visually stunning and ultra-modern looking but remain grounded in a prof-grade tool in look and feel. do as many rounds of sub-agent / peer review / self review as needed till you absolutely land on the most optimal ux style and fully apply that to every aspect of the ui at app shell level including all the panels etc. (the right side panel should also be collapsable same on the left panel, all using the most polished and sleek ux design grammar). use this screenshot to bootstrap your understanding of the photoshop but otherwise leverage your knowledge as well on what you know.
